## Matrix vs Discord: which one is better..?
### _Saturday, 12 September 2026 · buage_

---

Recently, I moved from Discord due to potentially upcoming age verification concerns. I saw multiple alternatives such as [Fluxer](https://fluxer.app), [Stoat](https://stoat.chat), [Root](https://www.rootapp.com/), etc. However, after trying [Matrix](https://matrix.org) with the [Sable](https://sable.moe) client, I think that it's the best alternative, at least in my opinion.

---

#### What is Matrix?

Matrix is an open-source decentralized communication protocol that allows users to chat even if they use different "homeservers" (Matrix instances).

I like to call it something like "the fediverse of communication." The Matrix protocol is resistant to censorship due to its decentralized nature and supports end-to-end encryption.

The best-known client allowing you to chat on the Matrix network is called [Element](https://element.io).

![Element client screenshot, from the Internet](/blog-content/posts/2/files/element.png)

The Element client is pretty decent, but I think it's not really the best. I think this for multiple reasons, which I will list below!

1) The user interface is, to be honest, not the easiest to understand for new users. It is very different from Discord, and I think this is a huge problem for users seeking alternatives to Discord.

2) The screen sharing system is not very good: the resolution of screen shares is very low, and the same for the framerate. That's very frustrating because Discord does really well at screen sharing.

3) It does not allow you to see who's in the voice chat before joining and shows DMs in the space, which is very confusing.

4) It does not support profile customization yet, and I think this is a very nice feature to have.

---

#### However, Sable can fix all of this!

Sable seems to be a good client that doesn't have any of these problems! It's a modern client with a Discord-like interface, which makes it suitable for people seeking Discord alternatives without wanting to get into anything technical!

![Sable web client screenshot, showing the homepage](/blog-content/posts/2/files/sable.png)

Sable is easy to use, and its interface is very easy to understand! It allows you to screen share in good resolution, with a decent framerate, although you cannot share the audio sometimes.

It comes with a lot of profile and theme customization built in, such as (animated) banners and profile pictures (like on Discord), profile colors, custom bio with pronouns, and even more!

All of this is free, unlike Discord, which only allows you to change your PFP and bio for free… how generous 🙄

---

#### I don't care about customization! Where are all the other features?

The Sable client has many other features for everyone, such as a GIF picker, uploading custom banners for spaces, account switcher, message bookmarking, spaces/rooms discovery, and many other cool features (go check them out!)

It also obviously supports end-to-end encrypted messages and video/voice calls (most Matrix clients do!)

---

#### So now, is Matrix better than Discord?

In my opinion, if you use the Sable client with Matrix, it can be as good as Discord or even better! It's obviously better than Discord if you seek a privacy-first alternative.

Now, if you're searching for maximum simplicity, then I would say that Stoat or any alternative might be better for you, but keep in mind that it's not as secure as Matrix.

But for me, Sable is by far the best alternative and the one I would recommend if you are at least a little "tech-savvy."

---

#### And why don't you just go to other alternatives?

It's very simple: most of them are centralized, which means that if their platform goes down, you can't chat with friends for the time that it's down. This also means that it is very easy to block and not very censorship resistant.

Another reason I think Matrix is better is because of the E2EE. It means that every message is encrypted before sending (if enabled), and if there is any data leak, all the messages are unreadable. That's very good for your security because most alternatives may not have this, and all the messages would leak in case of a data leak.

---

#### Conclusion

So to conclude this post, I think that Matrix can be at least as good as Discord, and maybe better with the Sable client!

Thank you for taking the time to read my post!
